01 / OVERVIEW

Safe autonomous driving requires more than accurate planning at a single frame: it demands reliable closed-loop execution in dynamic environments. Accumulated errors, especially in unseen scenarios, can push a vehicle into states from which the same policy struggles to recover.

We introduce AutoAgent0, an agentic runtime and harness framework that augments existing driving experts with complementary detection skills, rule-based action verification, and feedback-driven recovery. An independent detection module constructs scene context, while a shared verifier assesses trajectory feasibility before execution.

When nominal trajectories become unreliable, Recovery Planning constructs alternative maneuvers from action primitives and iteratively refines them using verification feedback. Fail2Drive results show improved closed-loop robustness across three experts without retraining them.
